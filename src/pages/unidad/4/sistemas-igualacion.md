<div id="metodo" class="lesson-box">
  <h2>Método de igualación</h2>
  <p>
    Consiste en despejar la <strong>misma variable</strong> en ambas ecuaciones
    y luego igualar las dos expresiones obtenidas.
  </p>
  <p><strong>Pasos:</strong></p>
  <ol>
    <li>Despejar la misma variable (x o y) en ambas ecuaciones</li>
    <li>Igualar las dos expresiones</li>
    <li>Resolver la ecuación resultante</li>
    <li>Sustituir el valor obtenido en cualquiera de las expresiones para hallar la otra variable</li>
  </ol>
  <p>Ejemplo rápido:</p>
  <p class="font-mono text-violet-400">
    x + y = 7<br>
    x - y = 3
  </p>
  <ol>
    <li>Despejamos x en ambas: x = 7 - y &nbsp;y&nbsp; x = 3 + y</li>
    <li>Igualamos: 7 - y = 3 + y</li>
    <li>7 - 3 = 2y → 4 = 2y → y = 2</li>
    <li>x = 7 - 2 = 5</li>
  </ol>
  <p class="font-mono text-violet-400">Solución: x = 5, y = 2</p>
</div>

<div id="problemas" class="lesson-box">
  <h2>Problemas resueltos paso a paso</h2>

  <h3>1)</h3>
  <p class="font-mono text-violet-400">x + y = 8<br>x - y = 2</p>
  <ol>
    <li>Despejamos x: x = 8 - y &nbsp;y&nbsp; x = 2 + y</li>
    <li>Igualamos: 8 - y = 2 + y</li>
    <li>6 = 2y → y = 3</li>
    <li>x = 8 - 3 = 5</li>
  </ol>
  <p class="font-mono text-violet-400">Solución: x = 5, y = 3</p>

  <h3>2)</h3>
  <p class="font-mono text-violet-400">2x + y = 10<br>x + y = 7</p>
  <ol>
    <li>Despejamos y: y = 10 - 2x &nbsp;y&nbsp; y = 7 - x</li>
    <li>Igualamos: 10 - 2x = 7 - x</li>
    <li>10 - 7 = 2x - x → 3 = x → x = 3</li>
    <li>y = 7 - 3 = 4</li>
  </ol>
  <p class="font-mono text-violet-400">Solución: x = 3, y = 4</p>

  <h3>3)</h3>
  <p class="font-mono text-violet-400">3x - y = 7<br>x + y = 5</p>
  <ol>
    <li>Despejamos y: y = 3x - 7 &nbsp;y&nbsp; y = 5 - x</li>
    <li>Igualamos: 3x - 7 = 5 - x</li>
    <li>4x = 12 → x = 3</li>
    <li>y = 5 - 3 = 2</li>
  </ol>
  <p class="font-mono text-violet-400">Solución: x = 3, y = 2</p>

  <h3>4)</h3>
  <p class="font-mono text-violet-400">x + 2y = 11<br>3x - 2y = 1</p>
  <ol>
    <li>Despejamos x: x = 11 - 2y &nbsp;y&nbsp; x = (1 + 2y)/3</li>
    <li>Igualamos: 11 - 2y = (1 + 2y)/3</li>
    <li>Multiplicamos por 3: 33 - 6y = 1 + 2y</li>
    <li>32 = 8y → y = 4</li>
    <li>x = 11 - 2(4) = 3</li>
  </ol>
  <p class="font-mono text-violet-400">Solución: x = 3, y = 4</p>

  <h3>5)</h3>
  <p class="font-mono text-violet-400">2x + 3y = 13<br>4x - y = 5</p>
  <ol>
    <li>Despejamos y: y = (13 - 2x)/3 &nbsp;y&nbsp; y = 4x - 5</li>
    <li>Igualamos: (13 - 2x)/3 = 4x - 5</li>
    <li>Multiplicamos por 3: 13 - 2x = 12x - 15</li>
    <li>28 = 14x → x = 2</li>
    <li>y = 4(2) - 5 = 3</li>
  </ol>
  <p class="font-mono text-violet-400">Solución: x = 2, y = 3</p>
</div>
