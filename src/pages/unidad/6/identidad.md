<div id="identidad" class="lesson-box">
  <h2>Identidades y ecuaciones</h2>
  <p>
    Una <strong>identidad</strong> es una igualdad algebraica que se cumple para <strong>cualquier
    valor numérico</strong> que tomen las variables.
  </p>
  <p class="font-mono text-violet-400">x + x = 2x</p>
  <p>
    Comprobamos que es una identidad probando varios valores:
  </p>
  <ul class="list-disc pl-5 marker:text-red-500">
    <li>Para x = 1 → 1 + 1 = 2 · 1 → 2 = 2 ✓</li>
    <li>Para x = −2 → (−2) + (−2) = 2 · (−2) → −4 = −4 ✓</li>
  </ul>
  <p>
    Una <strong>ecuación</strong> es una igualdad algebraica que <strong>solo es cierta para algunos
    valores</strong>.
  </p>
  <p class="font-mono text-violet-400">x + 4 = 10</p>
  <p>
    Solo se cumple cuando <strong>x = 6</strong> → 6 + 4 = 10. Para cualquier otro valor la igualdad
    es falsa.
  </p>
</div>

<div id="como-reconocer" class="lesson-box">
  <h2>¿Cómo distinguirlas?</h2>
  <p>
    Para saber si una igualdad algebraica es una identidad o una ecuación, sustituimos la variable
    por dos o tres valores distintos:
  </p>
  <ol>
    <li>
      Si la igualdad se cumple <strong>siempre</strong> (para todos los valores probados), es una
      <strong>identidad</strong>.
    </li>
    <li>
      Si la igualdad solo se cumple <strong>para algún valor</strong>, es una <strong>ecuación</strong>.
    </li>
  </ol>
  <p>Ejemplo:</p>
  <p class="font-mono text-violet-400">x + x + x = 3x</p>
  <ul class="list-disc pl-5 marker:text-red-500">
    <li>Con x = 2 → 2 + 2 + 2 = 3 · 2 → 6 = 6 ✓</li>
    <li>Con x = −1 → −1 − 1 − 1 = 3 · (−1) → −3 = −3 ✓</li>
  </ul>
  <p>Como se cumple para cualquier valor, es una <strong>identidad</strong>.</p>
</div>

<div id="problemas" class="lesson-box">
  <h2>Problemas resueltos paso a paso</h2>

  <h3>1) Comprobar que x + x = 2x es una identidad</h3>
  <ol>
    <li>Probamos x = 3 → 3 + 3 = 6 y 2 · 3 = 6 → 6 = 6 ✓</li>
    <li>Probamos x = −5 → −5 + −5 = −10 y 2 · (−5) = −10 → −10 = −10 ✓</li>
    <li>Como se cumple para distintos valores, es una identidad.</li>
  </ol>

  <h3>2) Comprobar que x + 4 = 10 es una ecuación</h3>
  <ol>
    <li>Probamos x = 6 → 6 + 4 = 10 → 10 = 10 ✓ (se cumple)</li>
    <li>Probamos x = 1 → 1 + 4 = 5 → 5 ≠ 10 ✗ (no se cumple)</li>
    <li>Como solo se cumple para un valor, es una ecuación.</li>
  </ol>

  <h3>3) Usar la propiedad distributiva como identidad</h3>
  <ol>
    <li>Partimos de 2(x + 3)</li>
    <li>Aplicamos la distributiva: 2 · x + 2 · 3 = 2x + 6</li>
    <li>Ambos miembros son idénticos: 2x + 6 = 2x + 6</li>
    <li>Se cumple para cualquier x → es una identidad ✓</li>
  </ol>
</div>

<div id="ejercicios" class="exercise-box">
  <h3>Ejercicios de práctica</h3>

  <h3>1) Indica si las igualdades son identidades o ecuaciones</h3>
  <ul class="exercise-list">
    <li>a) x + x = 2x</li>
    <li>b) 2(x + 3) = 2x + 6</li>
    <li>c) x + 5 = 12</li>
    <li>d) x + x + x = 3x</li>
    <li>e) 2x · x³ = 2x⁴</li>
    <li>f) x/2 = 12</li>
  </ul>

  <h3>2) Indica el valor de x para que se cumpla la igualdad</h3>
  <ul class="exercise-list">
    <li>a) x − 1 = 2</li>
    <li>b) x + 7 = 15</li>
    <li>c) x − 3 = 6</li>
    <li>d) x + 10 = 5</li>
    <li>e) x + 4 = 12</li>
    <li>f) x − 6 = 10</li>
  </ul>

  <h3>3) Razona qué tipo de igualdad es cada una</h3>
  <ul class="exercise-list">
    <li>a) 3x = x + x + x</li>
    <li>b) 5x + 2 = 17</li>
    <li>c) y + y = 2y</li>
    <li>d) 4(x − 2) = 4x − 8</li>
  </ul>
