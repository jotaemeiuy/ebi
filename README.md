# EBI 9C - Matemática

Sitio web de matemática para 9° EBI - UTU Uruguay.

##  Contenido

- **Unidad 1**: Números y Finanzas (Notación científica, Porcentajes, Interés)
- **Unidad 2**: Álgebra (Propiedad distributiva, Productos notables, Factorización)
- **Unidad 3**: Ecuaciones de primer grado (Igualdad, Transposición, Método general)
- **Unidad 4**: Ecuaciones de segundo grado (Ecuaciones cuadráticas)
- **Unidad 5**: Trigonometría (Pitágoras, Seno, coseno y tangente)
- **Unidad 6**: Función lineal
- **Unidad 7**: Función cuadrática
- **Unidad 8**: Sistemas de Ecuaciones

## 🚀 Deploy

### Vercel (recomendado)
1. Crear cuenta en [vercel.com](https://vercel.com)
2. Importar proyecto desde GitHub o drag & drop de la carpeta
3. Framework preset: Astro
4. Deploy

### Netlify
1. Crear cuenta en [netlify.com](https://netlify.com)
2. Drag & drop la carpeta `dist/` después de `pnpm build`

## 🧞 Comandos

| Comando                | Acción                                           |
| :--------------------- | :----------------------------------------------- |
| `pnpm install`         | Instalar dependencias                            |
| `pnpm dev`             | Iniciar servidor local en `localhost:4321`       |
| `pnpm build`           | Compilar sitio a `./dist/`                       |
| `pnpm preview`         | Previsualizar build localmente                   |

## 🛠 Tecnologías

- Astro 6
- Tailwind CSS 4
- Tema oscuro con colores violeta
